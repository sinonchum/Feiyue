Hermes Agent Console

Recommended architecture

The browser should talk to a Feiyue backend, not directly to Hermes credentials or provider APIs. A future Hermes Bridge sidecar can stream redacted session events here.

  1. Operator reviews evidence in Feiyue.
  2. UI submits an intent draft.
  3. Backend checks policy and approval gates.
  4. Hermes Bridge runs an allowed profile/session.
  5. Evidence is written under .hermes/ and refreshed here.
